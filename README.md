# Travel Website

This is a simple static travel website made using **HTML5**.  
It was created as part of an assignment to practice basic HTML elements.

## Features
- HTML5 boilerplate
- Headings, paragraphs, line breaks, and horizontal rules
- Text formatting: bold, italic, underline, strike
- Images of travel destination and activity
- Hyperlinks (internal, external, homepage)
- Ordered, unordered, and definition lists
- Travel packages table
- Contact section
- Comments in code

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.

## Assignment Info
**Title:** Design a Simple Travel Website using HTML  
**Objective:** Practice basic HTML structure and elements.
